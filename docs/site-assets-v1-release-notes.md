# site-assets-v1

This Release preserves downloadable research and project source artifacts that
were removed from the Git history during the Eleventy migration.

- Five Blender project files
- TUM CV Challenge SS24 poster
- TUM DI Lab report
- CSG-Fusion poster
- LiteTracker source teaser backup
- `SHA256SUMS` for integrity verification

These artifacts are provided for reference and retain their original ownership
and licensing. They are not covered by the repository's MIT License.

Verify a download with:

```bash
shasum -a 256 -c SHA256SUMS
```
