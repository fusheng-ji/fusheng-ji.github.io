# Web media derivatives

The repository tracks only browser-ready media derivatives. Source documents,
Blender projects, posters, and the preserved LiteTracker teaser are stored in
the `site-assets-v1` GitHub Release.

The migration generated:

- photographic WebP files at 640 px and 1280 px, quality 82;
- diagram WebP files at 640 px and 1280 px, quality 90;
- Rendering Work video as 1080p H.264, CRF 34, with `faststart`.

Image dimensions, alternative text, and local paths are validated from the
structured content data during every build.
